# Febius Fortuna 1.7.0 사용 설명서

엔진이 포함된 `FebiusFortuna.exe` 하나로 실행합니다. 별도 엔진 파일 설치는 필요하지 않습니다. 엔진의 소스와 SDK는 같은 저장소의 `engine/` 폴더에서 관리합니다.

## 시작하기

Windows 10 1607 이상 또는 Windows 11의 64비트 PC에서 실행 파일을 엽니다. 프로그램의 계정·라이선스 인증을 완료한 뒤 사용할 수 있습니다. 균등 무작위 추첨에는 CSV가 필요하지 않습니다. 프로그램은 시작 시 SHA-256, 조합 수, 운영체제 난수 동작을 검사합니다.

**1·5·10게임**을 선택한 다음 세 가지 추첨 버튼 중 하나를 누릅니다. **예상 번호 추첨**은 항상 균등 무작위입니다. **ORACLE기반 예상 번호 추첨**은 일반 분석, **ORACLE기반 심층 분석 추첨**은 정밀 연구 결과를 사용합니다. [동작과 계산 결과 재사용](DRAW_MODES.md)

한 게임 안에서는 1–45 중 서로 다른 여섯 번호가 오름차순으로 나옵니다. 세 방식 모두 게임별 독립 추출이므로 같은 게임이 반복될 수 있습니다.

## CSV와 분석

1. **CSV 불러오기**에서 [입력 형식](../engine/data/FORMAT.md)에 맞는 실제 과거 추첨 기록을 선택합니다.
2. 표시된 마지막 회차와 대상 회차를 확인합니다. 가상 예제는 사용법 확인용입니다.
3. 60회차 이상이면 일반 또는 심층 **ORACLE 추첨**을 누릅니다. 각 과거 시점의 전수 탐색을 다시 수행하므로 긴 데이터는 수 분 이상 걸릴 수 있습니다.
4. 진행 중에는 창을 이동하거나 분석을 취소할 수 있습니다. 데이터 교체·번호 생성은 분석과 동시에 실행하지 않습니다.
5. 완료하면 선택한 게임 수만큼 자동 추첨합니다. 같은 ORACLE 버튼은 완료된 분석을 재사용합니다.

잘못된 CSV를 선택해도 기존 데이터는 유지됩니다. 파일을 올바르게 교체하면 이전 분석은 무효화되므로 다시 분석해야 합니다. 분석 실패 또는 취소는 상태 표시로 알립니다. **예상 번호 추첨**으로 균등 무작위 추첨을 할 수 있습니다.

## 분석 수치 읽기

**분석 상세**의 `DEPTH VALIDATION`에는 관계 보정 오차, 순차 검정값,
재표본 구간, 성능 저하 누적값과 모형 제거 민감도가 표시됩니다.
재표본 횟수가 0이면 검증 회차가 부족한 상태입니다. 구간의 0은 확신을 뜻하지 않습니다.
일반은 최대 8개, 심층은 최대 16개 과거 시점을 새로 학습해 검증합니다.
[자세한 계산과 해석](../engine/docs/DEPTH_VALIDATION.md)

- **ORACLE 지수 0–1000**: 동일 모델로 평가한 균등 표본 512개 대비 해당 조합의 상대 점수 위치입니다. 전체 조합 중 정확한 백분위나 당첨확률이 아닙니다.
- **균등 혼합**: 실제 생성 정책에서 균등 추출을 선택하는 비율입니다. 100%는 검증 근거가 부족하여 과거 이력을 번호 선택에 반영하지 않는 상태입니다. 분석 자체가 실패했다는 뜻은 아닙니다.
- **후보장**: 정밀 평가를 통과한 512개 조합입니다. 이 안의 샘플링 확률은 추첨 당첨확률과 다릅니다.
- **백테스트**: 초기 60회를 지나 각 회차를 미래 정답으로 가린 순차 검증입니다. 120회 이상이면 마지막 30회를 가중치 학습에서 유보하며, 별도 확인까지 통과해야 가중 추출이 활성화됩니다.

**분석 상세**는 기록 폴더에 UTF-8 보고서를 작성하여 기본 텍스트 프로그램으로 엽니다. 파일 메뉴에서 원하는 위치에 내보낼 수도 있습니다. 보고서에는 해시, 학습·확인 지표, 모델 가중치·q값, 번호별 포함 확률, 후보별 안정성, 회차별 결과가 포함됩니다.

## 저장과 공식 번호

**복사**는 표시한 게임들을 Windows 클립보드에 넣습니다. **저장**은 UTF-16 텍스트 파일로 저장합니다.

**공식 번호 봉인**은 마지막 이력 다음 회차에 대한 번호를 결정론적으로 선택하고 `%LOCALAPPDATA%\Febius\Fortuna\predictions.flg`에 추가합니다. 같은 회차를 다시 봉인하면 기존 기록의 번호를 재사용합니다. 한국 시간 토요일 20:45 이후에는 해당 회차의 새 봉인을 거부합니다. 기존 기록은 재열람할 수 있습니다. 컴퓨터 시계와 입력 회차가 올바른지 확인하세요.

기록은 고정 길이의 SHA-256 연결 구조이며 변조·손상된 기록을 발견하면 덧붙이지 않습니다. 이 기능은 **로컬 기록**이며 외부 공증이나 신뢰할 수 있는 타임스탬프가 아닙니다. 폴더 전체를 백업해 두세요. 손상 오류가 나면 원본을 보존하고 정상 백업으로 복구합니다.

## 문제 해결

- 시작 자체 검사 실패: 릴리스 체크섬과 다운로드 파일을 확인합니다.
- 난수 생성 실패: 고정된 대체 번호를 내보내지 않습니다. Windows 상태를 확인한 뒤 재시도합니다.
- CSV 오류: 메시지의 오류 종류와 줄 번호를 보고 형식·범위·중복·누락·날짜를 확인합니다. 정렬 뒤 발견하는 오류의 줄은 원본 문제 행과 다를 수 있습니다.
- 긴 분석: 모델과 후보장을 모든 과거 시점에서 새로 계산하는 reference 구현입니다. **분석 취소**를 사용하세요.
- 보고서/봉인 저장 실패: 저장 폴더 쓰기 권한, 여유 공간과 다른 실행 중인 Fortuna를 확인합니다.

CLI는 `--open <CSV 경로>`로 GUI를 시작할 수 있으며, `--self-test`, `--analyze <CSV 경로> <보고서 경로>`를 지원합니다. 성공 0, 분석/파일 오류 1, 잘못된 인수 2를 반환합니다. 자체 검사의 10 이상 코드는 실패 단계입니다. 경로에 공백이 있으면 큰따옴표로 감쌉니다.

## 정밀 연구 분석

CSV를 불러온 뒤 **ORACLE기반 심층 분석 추첨**을 실행합니다. 완료 후 **분석 상세**에서 모델 제거 비교, 공동 확률모형의 평가, 후보 누락 검사와 불확실성을 확인합니다. 기본 분석보다 훨씬 오래 걸릴 수 있고 **분석 취소**를 사용할 수 있습니다.

일반·심층 버튼 모두 열 가지 통합 수학 기능을 기본 실행합니다. 심층 버튼은 통합 모형과 균등 분포의 50:50 혼합을 사용합니다. 일반 ORACLE은 기존 검증 정책이 허용하는 범위에서 통합 모형을 혼합하고, 랜덤 버튼은 균등 무작위입니다. 연구 모델의 실제 당첨 예측력이 입증되었다는 뜻은 아닙니다.

정밀 연구를 마친 다음 **기존 공동모형 확률분포 기록**으로 기존 공동모형의 예측 분포를 고정합니다. 이 기록은 새 통합 추첨 모형의 분포와 다릅니다. 다음 추첨 결과를 CSV에 추가해 불러온 후 **기존 공동모형 기록 검증**을 실행하면 기록 당시 분포로 평가합니다. 같은 회차를 다시 평가해도 평가 건수가 늘어나지 않습니다. 결과 보고서를 열려면 일반/연구 분석이 완료된 상태여야 합니다. 분석은 기록 검증 상태를 초기화하므로 **분석 후 기록 검증 → 분석 상세** 순서로 확인하세요.

기록은 `%LOCALAPPDATA%\Febius\Fortuna\oracle-forecasts.fjp`에 저장합니다. 과거 행이 수정되거나 기록이 손상되면 검증을 거부합니다. 신뢰할 수 있는 외부 사본을 보관하세요. 기록 전체의 재작성이나 컴퓨터 시계 조작을 외부에서 증명하는 기능은 없습니다.

`--research <CSV> <보고서>`는 정밀 연구, `--research-full <CSV> <보고서>`는 전체 깊은 점수 계산까지 실행합니다. 후자는 매우 오래 걸릴 수 있습니다. [자세한 수식·평가 범위](../engine/docs/RESEARCH.md)
