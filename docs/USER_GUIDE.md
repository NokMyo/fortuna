# Febius Fortuna 1.0.0 사용 설명서

## 시작하기

Windows 10 1607 이상 또는 Windows 11의 64비트 PC에서 실행 파일을 엽니다. 번호 생성은 인터넷·CSV 없이 동작합니다. 프로그램은 시작 시 SHA-256, 조합 수, 운영체제 난수 동작을 검사합니다.

**번호 생성**은 1게임, **5게임 / 10게임**은 번호 중복을 줄인 묶음을 생성합니다. 한 게임 안에서는 1–45 중 서로 다른 여섯 번호가 오름차순으로 나옵니다. 묶음 안에 동일한 게임을 반복하지 않으며, 게임 사이에는 일부 번호가 겹칠 수 있습니다. 묶음은 순차적인 다양성 최적화를 거치므로 독립 추출과 분포가 다릅니다.

## CSV와 분석

1. **CSV 불러오기**에서 [입력 형식](../data/FORMAT.md)에 맞는 실제 과거 추첨 기록을 선택합니다.
2. 표시된 마지막 회차와 대상 회차를 확인합니다. 가상 예제는 사용법 확인용입니다.
3. 60회차 이상이면 **오라클 분석**을 누릅니다. 각 과거 시점의 전수 탐색을 다시 수행하므로 긴 데이터는 수 분 이상 걸릴 수 있습니다.
4. 진행 중에는 창을 이동하거나 분석을 취소할 수 있습니다. 데이터 교체·번호 생성은 분석과 동시에 실행하지 않습니다.
5. 완료하면 새 번호를 생성합니다. **번호 생성**은 모델을 다시 학습하지 않습니다.

잘못된 CSV를 선택해도 기존 데이터는 유지됩니다. 파일을 올바르게 교체하면 이전 분석은 무효화되므로 다시 분석해야 합니다. 분석 실패 또는 취소 시 균등 생성으로 복귀합니다.

## 분석 수치 읽기

- **ORACLE 지수 0–1000**: 동일 모델로 평가한 균등 표본 512개 대비 해당 조합의 상대 점수 위치입니다. 전체 조합 중 정확한 백분위나 당첨확률이 아닙니다.
- **균등 혼합**: 실제 생성 정책에서 균등 추출을 선택하는 비율입니다. 100%는 검증 근거가 부족하여 과거 이력을 번호 선택에 반영하지 않는 상태입니다. 분석 자체가 실패했다는 뜻은 아닙니다.
- **후보장**: 정밀 평가를 통과한 512개 조합입니다. 이 안의 샘플링 확률은 추첨 당첨확률과 다릅니다.
- **백테스트**: 초기 60회를 지나 각 회차를 미래 정답으로 가린 순차 검증입니다. 120회 이상이면 마지막 30회를 가중치 학습에서 유보하며, 별도 확인까지 통과해야 가중 추출이 활성화됩니다.

**분석 상세**는 기록 폴더에 UTF-8 보고서를 작성하여 기본 텍스트 프로그램으로 엽니다. 파일 메뉴에서 원하는 위치에 내보낼 수도 있습니다. 보고서에는 해시, 학습·확인 지표, 모델 가중치·q값, 번호별 포함 확률, 후보별 안정성, 회차별 결과가 포함됩니다.

## 저장과 공식 번호

**복사**는 표시한 게임들을 Windows 클립보드에 넣습니다. **저장**은 UTF-16 텍스트 파일로 저장합니다.

**공식 번호 봉인**은 마지막 이력 다음 회차에 대한 번호를 결정론적으로 선택하고 `%APPDATA%\Febius\Fortuna\prediction-ledger.bin`에 추가합니다. 같은 회차를 다시 봉인하면 기존 기록의 번호를 재사용합니다. 한국 시간 토요일 20:45 이후에는 해당 회차의 새 봉인을 거부합니다. 기존 기록은 재열람할 수 있습니다. 컴퓨터 시계와 입력 회차가 올바른지 확인하세요.

기록은 고정 길이의 SHA-256 연결 구조이며 변조·손상된 기록을 발견하면 덧붙이지 않습니다. 이 기능은 **로컬 기록**이며 외부 공증이나 신뢰할 수 있는 타임스탬프가 아닙니다. 폴더 전체를 백업해 두세요. 손상 오류가 나면 원본을 보존하고 정상 백업으로 복구합니다.

## 문제 해결

- 시작 자체 검사 실패: 릴리스 체크섬과 다운로드 파일을 확인합니다.
- 난수 생성 실패: 고정된 대체 번호를 내보내지 않습니다. Windows 상태를 확인한 뒤 재시도합니다.
- CSV 오류: 메시지의 오류 종류와 줄 번호를 보고 형식·범위·중복·누락·날짜를 확인합니다. 정렬 뒤 발견하는 오류의 줄은 원본 문제 행과 다를 수 있습니다.
- 긴 분석: 모델과 후보장을 모든 과거 시점에서 새로 계산하는 reference 구현입니다. **분석 취소**를 사용하세요.
- 보고서/봉인 저장 실패: 저장 폴더 쓰기 권한, 여유 공간과 다른 실행 중인 Fortuna를 확인합니다.

CLI는 `--self-test`, `--analyze <CSV 경로> <보고서 경로>`를 지원합니다. 성공 0, 분석/파일 오류 1, 잘못된 인수 2를 반환합니다. 자체 검사의 10 이상 코드는 실패 단계입니다. 경로에 공백이 있으면 큰따옴표로 감쌉니다.
