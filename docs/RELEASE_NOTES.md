Febius Fortuna 1.2.0 — 엔진 전용 폴더와 단일 실행 파일

- 기존 fortuna 저장소 안에서 ORACLE의 소스·설계 문서·테스트·SDK를 `engine/` 폴더로 정리했습니다.
- 엔진만 독립적으로 빌드할 수 있고, 앱은 공개 API를 통해 연결합니다. 앱과 엔진 버전도 따로 관리합니다.
- 일반 배포는 엔진이 포함된 `FebiusFortuna.exe` 하나로 실행합니다. 별도 엔진 DLL이 필요 없습니다.
- 앱과 엔진 실행 로직은 x64 어셈블리입니다. 기존 클래식 Windows 화면과 분석 기능을 유지합니다.
- 수학 검증, Windows 엔진 API 검사와 단일 EXE의 자체 검사·한글 경로·GUI 번호 생성을 검증합니다.

Windows x64 ZIP을 받아 압축을 풀고 `FebiusFortuna.exe`를 실행하세요. 설명서와 가상 데이터 예제가 포함되어 있습니다. 이전 릴리스를 덮어쓰지 않습니다.

이번 변경은 코드 구조와 배포 방식의 정리입니다. 엔진의 수학적 구현 범위와 장기 연구 항목은 `engine/docs/IMPLEMENTATION.md`에 명시되어 있으며, 내부 지수는 당첨확률이 아닙니다.
