Febius Fortuna 1.3.0 / ORACLE Engine 1.1.0

- 공동 확률모형: 모든 8,145,060개 조합에 대해 확률 합과 번호·쌍·삼중 포함 확률 계산.
- 단계별 경험적 베이지안 축소와 희소화로 근거가 약한 상호작용 억제.
- 탈락 후보 감사, 발견 시 4,096→8,192개 확장, 선택 가능한 전체 깊은 점수 탐색.
- 기존 12개 성분을 하나씩 제외한 전체 분석 12회와 기준 분석 1회 비교.
- 중첩 시간순 공동 모형 평가, 로그 손실, 추첨 전 분포 기록과 누적 log-e 검증.
- 학습 창·설정·모형 차수의 적응적 섭동, 불확실성과 계산 오차 보고.

앱의 분석 메뉴에 정밀 연구, 연구용 공동 모형 번호 생성, 다음 회차 확률분포 기록·검증 기능을 추가했습니다. 연구는 계산량이 크며 취소할 수 있습니다. 기존 번호 생성은 기존 검증 정책을 사용합니다. 연구 모형의 실제 로또 예측 우위는 아직 입증되지 않았습니다.

모든 실행 로직은 x64 어셈블리이며, 같은 저장소의 engine 폴더에서 관리하고 단일 EXE에 포함합니다. Windows x64 ZIP을 풀어 FebiusFortuna.exe를 실행하세요.

독립 확률 계산, 미래 데이터 차단, 기존 엔진 회귀 검사, Windows 연구 API·예측 기록·단일 EXE 명령 검사를 통과한 빌드를 배포합니다. 수식의 정확한 구현 범위와 제한은 engine/docs/RESEARCH.md에 있습니다. 기존 릴리스는 덮어쓰지 않습니다.
