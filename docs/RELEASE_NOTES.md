# Febius Fortuna 1.6.0 / Engine 1.4.0

일반·심층 ORACLE에 열 가지 수학 기능을 공통 기본 탑재했습니다.
고차 확률모형, 유한 계수 적분, 다단계 확률 탐색, 변화점,
가상 이력 재학습, 텐서, 동적 상태, 시간순 모형 결합,
분포 강건 최적화, 정규화 상수 경계 계산을 포함합니다.

일반과 심층은 동일한 기능을 사용하며 계산 범위가 다릅니다.
분석 결과를 실제 추첨 확률에 연결하고, 확률 조회 API와 계산 보고서를 추가했습니다.
앱·엔진 실행 로직은 모두 x64 어셈블리입니다. 기존 계정·라이선스 검사를 유지합니다.

계수 적분은 경험적 베이지안 유한 격자 방식이고, 동적 상태는 주변 확률 근사입니다.
수치 경계는 기계적으로 증명된 구간 연산이 아닙니다. 계산 시간이 정확히 1시간이거나
예측 우위가 보장되는 것은 아닙니다. 기존 예측 기록 기능은 기존 공동모형을 기록하며,
새 통합 모형과 구분해 표시합니다. 자세한 범위는 engine/docs/INTEGRATED_INFERENCE.md에 있습니다.
