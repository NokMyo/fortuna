# Febius Fortuna 1.7.0 / Engine 1.5.0

일반·심층 ORACLE 모두에 더 깊은 계산과 검증을 추가했습니다.

- 16·64·256회차·전체 이력의 베타 추정과 시간순 성능 가중치
- 번호 간 관계 행렬 보정과 수렴 오차 검사
- 정규화 상수의 보상 합산, 에너지 평균·피셔 곡률과 확률 일관성 검사
- 미래 결과를 보기 전에 가중치를 정하는 온라인 혼합과 순차 검정
- 시간·모형 다중 검정 보정, 블록 재표본 구간, 모형 제거 민감도·성능 저하 진단

일반/심층의 시간순 재학습 검증은 최대 8/16회, 블록 재표본은 512/4096회입니다.
검증 구간이 8회보다 짧으면 재표본 구간은 제공하지 않습니다. 일반 모드는 추가
검증 문턱을 통과해야 이력 반영 비중을 허용하며, 심층은 연구용 혼합을 유지합니다.

앱과 엔진 실행 로직은 x64 어셈블리입니다. 같은 저장소의 engine/ 폴더,
단일 EXE 배포, 기존 계정·라이선스 검사를 유지하며 96바이트 진단 API를 추가했습니다.

독립 수식 대조, 작은 귀무 이력 전체 열거, 재표본 분산과 미래 정보 격리 검사를 포함합니다.
계산 시간은 입력과 PC에 따라 달라지며 예측 우위를 보장하지 않습니다. 재표본 구간과
수치 보정에는 근사가 포함됩니다. 기존 예측 기록은 기존 공동모형의 분포를 기록합니다.
수식과 해석 범위는 engine/docs/DEPTH_VALIDATION.md에 정리했습니다.
