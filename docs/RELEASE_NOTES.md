# Febius Fortuna 1.10.0 / Engine 1.7.0

분석 범위와 로그인/UI 동작을 정리했습니다.

- 로그인창은 처음 열릴 때 상태 문구를 비워 두고, 아이디·비밀번호 입력값이 유효하지 않을 때만 `유효한 값을 입력하십시오.` 표시
- 기존의 하단 ORACLE 지수 안내 문구와 내장 데이터 로드/검증 문구 제거
- 분석 범위를 **실제 사용할 과거 회차 범위**로 변경
- 기본 범위는 내장 데이터 전체인 `1~1242`
- 화면에 현재 데이터의 사용 가능 범위와 최소 선택 길이 60회를 표시
- 예: `1~432`를 선택하면 1~432회차만 일반·심층 ORACLE의 최종 fitting, 검증, 보고서에 사용하고 다음 대상은 433회차
- 범위 밖의 미래 회차는 최종 모델에도 사용하지 않도록 전체 원본 데이터와 활성 분석 데이터를 분리
- 분석 중 백테스트 진행 수 역시 선택 범위를 기준으로 계산

예상 소요시간은 현재 PC에서 측정한 계산 성능과 선택 범위를 이용한 추정치입니다.
