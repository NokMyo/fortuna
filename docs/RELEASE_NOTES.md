# Febius Fortuna 1.9.0 / Engine 1.6.0

로그인 화면과 ORACLE 분석 흐름을 정리하고 사용자 지정 백테스트 범위와 하드웨어 기반 예상시간 표시를 추가했습니다.

- Febius Account 로그인 화면을 아이디·비밀번호·상태 문구 중심으로 단순화
- 초기 안내를 `유효한 값을 입력하십시오.`로 통일하고 비밀번호 저장 설명 문구 제거
- 일반·심층 ORACLE에서 inclusive 백테스트 시작·종료 회차를 직접 지정
- 각 백테스트 대상 회차는 그 이전 데이터만 학습하고 선택 범위의 마지막 30회는 독립 확인으로 유보
- 선택 범위는 최소 60회, 첫 대상 이전 학습 이력은 최소 60회로 제한
- 범위 변경 시 기존 분석 캐시를 무효화하고 같은 데이터·같은 범위에서는 완료 결과 재사용
- 실행 시 CPU 마이크로벤치마크를 수행하고 선택한 범위와 일반/심층 계산 구조를 반영해 분 단위 예상 소요시간 표시
- 화면 문구를 `균등 무작위`, `일반 분석 • N분 예상소요시간`, `정밀 분석 • N분 예상소요시간`으로 정리
- 보고서에 실제 백테스트 대상 범위·선택 대상 수·확인 fold 수 기록

예상 소요시간은 현재 PC에서 측정한 계산 성능을 이용한 추정치이며 실제 완료시간을 보장하지 않습니다. ORACLE 분석 결과는 당첨 확률 우위를 의미하지 않습니다.
